# 一键加速安全变更说明

## 2026-10-13 一键加速回滚与 Zone SSL 隔离

本轮仅调整一键加速流程，原有 SSL/TLS 页面继续支持管理员主动修改区域设置。

- 一键加速不再调用 `PATCH /zones/:zoneId/settings/ssl`；只读取并返回原模式，`sslSetting.changed=false`。
- 写前读取 Zone、DNS、SSL、SaaS 回退源、自定义主机名，先检查所有已知冲突。
- 访问域名 CNAME 放在最后写入；既有自定义主机名只更新源站，保留证书参数、SNI 和元数据。
- 新增 `SpeedDeployTransaction`，在发送写请求前注册补偿，支持处理远端已应用但响应失败的情况；逆序恢复并读取确认。
- 回滚失败、配置被其他操作修改或写入结果尚未确认时，接口和页面明确提示恢复未完成，不静默吞掉错误。
- 同面板进程、同 Cloudflare 登录账号、同 Zone 使用执行锁，防止加速与删除请求交错。
- 不覆盖其他 SaaS 回退源、访问域名非 CNAME 记录和无法安全恢复的默认源站配置。
- 页面解释沿用当前 SSL 模式和失败恢复行为；成功页面改为提示等待 DNS 与证书验证。
- Cloudflare API 恢复接口依据官方 DNS、Custom Hostnames 与 Fallback Origin 文档；既有默认源站的清空语义未得到明确确认，因此预检查拒绝覆盖这种配置。

验证使用本地隔离 Cloudflare 模拟服务，覆盖成功流程、五种 SSL 模式、四个写入阶段应用前/后失败、DNS 和自定义源站恢复、连接断开、超时、恢复失败、并发冲突以及 HTTP 恢复结果响应。未操作真实 Cloudflare 配置。

验证结果：完整 `npm test` 96 项通过，117 个 JavaScript 文件语法检查通过，`git diff --check` 通过；独立审查的 37 项加速定向测试通过。

边界：补偿快照在内存中，不提供强制终止后的持久化续跑；跨实例/外部控制台修改不受执行锁约束。详细恢复语义见 DEPLOYMENT.md 的“一键加速的变更与恢复”。


## 2026-10-14 持久化任务与操作历史

SQLite 操作历史替代原内存记录，保留最近 3000 条，提供账号、域名、模块、状态和时间筛选，并区分部分完成与结果未确认。

部署与加速域名删除现在写入加密任务日志。每步先记录写入意图，再保存确认结果；中断后通过页面检查，部署可恢复已确认且未被外部修改的资源，删除任务只允许人工处理。SQLite 区域锁、进程身份与租约覆盖同库多实例；任务未处理时阻止同区域新任务及账号删除。

此更新替代上轮“快照仅在内存、锁仅限同进程”的边界。不会重建升级前的内存记录，不会在启动时自动写入 Cloudflare。使用和限制见 [部署文档](../DEPLOYMENT.md#一键加速的变更与恢复) 与 [任务恢复说明](./speed-task-recovery.md)。
