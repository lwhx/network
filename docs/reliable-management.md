# 管理可靠性与账号维护

## 页面切换

账号、域名和资源切换后，旧请求的成功结果、错误提示和完成状态不会覆盖当前页面。同一数据的多次刷新只接受最新请求。账号切换会取消旧账号的读取；页面导航取消旧页面的读取并清理忙碌状态，同一账号全局共享的域名列表继续加载，避免登录后快速导航导致空列表。

写入请求发出后仍可能在 Cloudflare 完成。切换页面不会撤销远端写入；返回原页面后通过刷新查看实际结果。

## 完整响应超时与错误反馈

Cloudflare 客户端在完整读完响应内容后才结束超时计时。网络响应先返回 HTTP 头、后续内容停滞时，读取会返回 504；若已经观察到 HTTP 错误状态，则保留该状态，HTTP 5xx 的写入仍视为结果未确认。适用 JSON、文本、原始响应、Multipart 和只读 GraphQL 查询。原始响应在客户端完整缓冲后返回，保留当前调用方使用的状态、头部和字节内容；不提供提前返回的网络流。

写入结果未确认会提示先核查远端配置，不自动重试。非服务端错误的明确 `success:false` 拒绝响应继续作为失败处理；Multipart 成功必须包含 `success:true`。异常 Multipart 2xx 失败统一返回 502，防止页面误报成功。统计 GraphQL 必须返回有效 `data` 对象且没有错误；缺失或异常响应不再当成空统计。

DNS 工具栏新增“刷新 DNS 记录”，加载时禁用，超时结束后可再次读取。复用原有账号、域名及请求版本保护；当前域名的批量结果会保留，刷新不会重试任何写入。

参考 [Cloudflare GraphQL 错误响应](https://developers.cloudflare.com/analytics/graphql-api/errors/) 与 [Node.js fetch](https://nodejs.org/docs/latest-v24.x/api/globals.html#fetch)。验证使用本地 HTTP 服务先发送部分响应内容，再暂停发送，覆盖读取超时、写入不确定性、批量停止、手动刷新及移动端布局。

## 批量 DNS

添加和删除在开始前校验所有输入，单次最多 100 条。输入无效时整批不发送写入。操作逐条执行，每条显示以下结果：

| 结果 | 含义 | 重试 |
| --- | --- | --- |
| 成功 | 已收到有效的成功响应 | 不重试 |
| 失败 | Cloudflare 明确拒绝操作 | 可重试 |
| 结果未确认 | 请求超时、连接中断、服务端错误或成功响应无法确认 | 先刷新并人工核查，不自动重试 |
| 未执行 | 前一项结果未确认，后续写入已停止 | 可重试 |

明确失败后继续处理其他项目；结果不确定时停止后续写入。“仅重试失败和未执行项”只发送这些输入，并保留之前已成功项目的结果。批量删除重试仍需确认。页面报告保存在当前页面内存中，不是持久任务记录。

接口保留 `records` / `deleted` 成功项目数组，新增 `results` 和 `summary`。全部成功返回添加 201、删除 200；部分成功、失败或未确认返回 207，客户端应读取逐条结果，不能只根据 HTTP 成功判断整批成功。

## Cloudflare 账号管理

顶部“账号管理”可以编辑保存的账号名称、登录邮箱和 Global API Key。密钥输入框始终为空，不回显已保存密钥；留空保留现有值，填写新值才替换。服务端继续加密保存密钥。

“测试连接”使用当前表单中的信息，留空的密钥使用服务端保存值；只读取 Cloudflare 域名列表，不保存表单、不修改远端资源。测试仅验证该读取接口可用，不代表所有功能或套餐权限均可用。

删除只移除面板中的凭据。删除当前账号后切到剩余账号；删除最后一个账号后，管理员保持登录并进入添加 Cloudflare 账号页面。

详情读取、编辑、删除和测试均要求登录；状态修改请求继续检查 CSRF 和同源。详情仅向已登录管理员展示完整邮箱，接口和日志不返回 API Key。

## KV Key 分页与编辑

KV 命名空间详情默认读取 50 个 Key，点击“加载更多”继续浏览。搜索按 Key 名称前缀匹配，支持中文，区分大小写；这是 Cloudflare 前缀查询，不是 Value 内容搜索。改变筛选或点击“清除筛选”从第一页开始；“刷新 Key 列表”重新读取当前筛选的第一页。

已加载的 Key 按名称去重。读取下一页失败时保留现有列表和游标，可手动重试。空页仍有游标时允许继续加载；游标重复或循环时报告异常，需刷新后继续，不自动扫描整个命名空间。页面显示已加载数量，不将其当作命名空间总数。

搜索、分页、刷新及保存后的列表更新会保留编辑框内容。输入新草稿、保存或删除会让较早的 Value 读取响应失效；只有成功读取后才一起替换 Key 与 Value，读取失败保留原编辑内容。写入期间禁用重复提交和其他 Key 的读取、删除。保存过程中继续编辑会保留新草稿，并提示当前内容尚未保存。关闭详情、换命名空间或换账号会清空该编辑内容；草稿仅存在当前页面内存，不自动保存。

新增只读接口 `GET /api/developer-resources/kv/:namespaceId/keys`，参数 `accountId`、`prefix`、`cursor`、`limit`，返回 `{page: {accountId, namespaceId, keys, prefix, limit, cursor, hasMore}}`。接口检查管理员登录和当前凭据可访问的 Cloudflare Account；每页 10-1000 条（默认 50），前缀最多 512 字节，面板限制游标为 4096 字节并原样传递。既有详情的 `extras.keys` 数组继续保留，新增 `extras.keyPage` 分页信息。

保存或删除后刷新当前前缀的第一页。分页不是固定快照，外部写入和 KV 的数据传播可能改变结果，必要时手动刷新。接口和页面不新增自动重试写入，也不需要数据库迁移或新的环境变量。API 参数依据 [Cloudflare KV Key 列表文档](https://developers.cloudflare.com/api/resources/kv/subresources/namespaces/subresources/keys/methods/list/)；验证使用隔离模拟服务，包含 106 个 Key、中文前缀、失败重试、旧响应保护、读写竞态及 390px 手机布局。

## 验证与发布

PR 检查以只读权限运行语法检查、Node 回归和 Playwright 浏览器测试，不使用生产账号或发布密钥。主分支的 Docker 构建与发布流程继续保留。

回归覆盖请求乱序、旧请求错误、页面切换、批量部分成功、未知写入结果、失败重试、账号密钥保留与加密替换、权限与 CSRF、删除后的账号回退，以及登录和手机布局。
