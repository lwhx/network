# 管理可靠性与账号维护

## 页面切换

账号、域名和资源切换后，旧请求的成功结果、错误提示和完成状态不会覆盖当前页面。同一数据的多次刷新只接受最新请求。账号切换会取消旧账号的读取；页面导航取消旧页面的读取并清理忙碌状态，同一账号全局共享的域名列表继续加载，避免登录后快速导航导致空列表。

写入请求发出后仍可能在 Cloudflare 完成。切换页面不会撤销远端写入；返回原页面后通过刷新查看实际结果。

## 批量 DNS

添加和删除在开始前校验所有输入，单次最多 100 条。输入无效时整批不发送写入。操作逐条执行，每条显示以下结果：

| 结果 | 含义 | 重试 |
| --- | --- | --- |
| 成功 | 已收到有效的成功响应 | 不重试 |
| 失败 | Cloudflare 明确拒绝操作 | 可重试 |
| 结果未确认 | 请求超时、连接中断、服务端错误或成功响应无法确认 | 先刷新并人工核查，不自动重试 |
| 未执行 | 前一项结果未确认，后续写入已停止 | 可重试 |

明确失败后继续处理其他项目；结果不确定时停止后续写入。“仅重试失败和未执行项”只发送这些输入，并保留之前已成功项目的结果。批量删除重试仍需确认。页面报告保存在当前页面内存中，不是持久任务记录。

接口保留 `records` / `deleted` 成功项目数组，新增 `results` 和 `summary`。全部成功返回添加 201、删除 200；部分成功、失败或未确认返回 207，客户端应读取逐条结果，不能只根据 HTTP 成功判断整批成功。

## Cloudflare 账号管理

顶部“账号管理”可以编辑保存的账号名称、登录邮箱和 Global API Key。密钥输入框始终为空，不回显已保存密钥；留空保留现有值，填写新值才替换。服务端继续加密保存密钥。

“测试连接”使用当前表单中的信息，留空的密钥使用服务端保存值；只读取 Cloudflare 域名列表，不保存表单、不修改远端资源。测试仅验证该读取接口可用，不代表所有功能或套餐权限均可用。

删除只移除面板中的凭据。删除当前账号后切到剩余账号；删除最后一个账号后，管理员保持登录并进入添加 Cloudflare 账号页面。

详情读取、编辑、删除和测试均要求登录；状态修改请求继续检查 CSRF 和同源。详情仅向已登录管理员展示完整邮箱，接口和日志不返回 API Key。

## 验证与发布

PR 检查以只读权限运行语法检查、Node 回归和 Playwright 浏览器测试，不使用生产账号或发布密钥。主分支的 Docker 构建与发布流程继续保留。

回归覆盖请求乱序、旧请求错误、页面切换、批量部分成功、未知写入结果、失败重试、账号密钥保留与加密替换、权限与 CSRF、删除后的账号回退，以及登录和手机布局。
